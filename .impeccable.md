## Design Context

### Users

AI engineers and technical readers discovering the project on GitHub and Twitter. They need to see what the system really does and reproduce the result.

### Brand Personality

Precise, candid, kinetic. The user asked for an impressive showcase and emphasized native C++ and low latency engineering.

### Aesthetic Direction

Preserve the established paper, dark ink, and vermillion palette with Instrument Serif display and Manrope interface text. Use a clear side by side stream comparison as the main new interaction. This follows the existing design while the optional visual preference question remains unanswered.

### Design Principles

- Put the actual intervention before architectural explanation.
- Distinguish model output, injected test conditions, and observed controller events.
- Show measured numbers with their units and limits.
- Use motion to reveal streaming and interruption.
- Keep every control keyboard accessible and honor reduced motion.
